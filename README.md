# 班編成＆席替えジェネレーター（完全スタンドアロン版）

学校現場・学級経営のための**班編成＆席替え自動生成Webアプリケーション**です。  
サーバーや外部データベース、APIキー、Node.jsなどの環境構築は一切不要。**ブラウザだけで完全にオフライン動作**します。

---

## 🌟 主な特徴・機能

1. **先生用ゼロ設定（非公開設定）**
   - 生徒名簿の一括登録（Excel / スプレッドシートからのコピー＆ペースト自動パース対応）
   - ふりがな自動推測・男女別人数管理
   - ペア制限（「離したいペア」および「一緒にしたいペア」の指定）
   - 座席希望（前席・後席・窓側・廊下側などの個別配慮）

2. **生活班編成ウィザード**
   - 班数・班名の自由設定
   - 男子・女子の各班人数均等配分および個別調整
   - 男子リーダー・女子リーダー（班長）の任命
   - ペア条件を考慮した自動シャッフル生成
   - 役割・係分担の割り当て
   - 生活班名簿＆役割分担表のA4印刷・Word形式（.doc）保存

3. **席替えジェネレーター**
   - **編成済み生活班の呼び出し・連動機能**（「班編成を更新する」ボタンで最新の班情報をワンクリック同期）
   - 列数・行数の柔軟な設定（2〜10列 × 2〜10行）
   - 配置パターンの選択（男女ランダム / 市松模様（男女交互））
   - 空席・除外席のフリック/タップ指定
   - 生活班ブロック配置（各班を教室内でまとまって座らせるエリア指定）
   - ワクワクの自動配置実行演出（5秒カウントダウン）
   - クリックでの直感的な手動席入れ替え・微調整
   - ペア制約や市松模様の達成状況表示

4. **印刷＆保存**
   - **A4用紙ジャストフィット印刷対応**（専用印刷CSS内包）
   - 生徒名がくっきりと太字で印字される高視認性レイアウト
   - 生徒用（教卓が上）／教師用（教卓が下）の切り替え＆2種類まとめて印刷
   - 単一HTMLファイル保存（.html）および Word形式保存（.doc）

5. **全画面「生徒用画面に戻る」ナビゲーション完備**
   - どのステップ・設定画面からでもワンクリックで生徒用メニューに戻れます。

## 🚀 使い方

### ① Webブラウザで使う場合（GitHub Pages）
本リポジトリの **Settings > Pages** で「Deploy from a branch (main / root)」を有効にすると、ブラウザからURLでアクセスできます。

### ② パソコン上で直接使う場合（オフライン・校務PC）
1. `index.html`（または `sekigae_full_app.html`）をダウンロードします。
2. ファイルをダブルクリックするだけで、Google Chrome や Microsoft Edge、Safari 等のブラウザでそのまま起動します。
3. インターネット接続不要で、入力したデータはブラウザ（LocalStorage）に自動保存されます。
