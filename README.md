# 班編成＆席替えジェネレーター（完全スタンドアロン版）

小・中・高校の学級経営・学校現場向けに設計された**班編成＆席替え自動生成Webアプリケーション**です。  
Node.jsやサーバー、外部データベース、APIキー等の環境構築は一切不要。**ブラウザだけで完全にオフライン動作**します。

---

## 🌟 主な機能と特徴

### 1. 先生用ゼロ設定（非公開設定）
- **生徒名簿の一括登録**: Excel や Googleスプレッドシートからコピー＆ペーストするだけで、出席番号・氏名・ふりがな・性別を自動解析して登録できます。
- **ペア配慮（離す・一緒にする）**: トラブル防止や相性を考慮したペア条件を直感的に設定。
- **個別座席希望**: 「視力や健康上の配慮で最前列」「窓側希望」などの個別希望を設定可能。
- **生活班の事前定義＆希望配置**: 先生用画面からあらかじめ生活班の名称（1班〜8班、自由な班名）を事前入力・決定可能。各班ごとの希望位置（前方・中央・後方、窓側・中央・廊下側）も設定可能。

### 2. 途中中断・自動保存（自動更新機能）
- **途中までの進捗を完全自動保存**: 班編成ウィザードや席替え設定の途中でブラウザを閉じたり、画面を行き来しても、LocalStorageに即座に自動保存されます。
- **続きから再開 / 最初からやり直し**: メニュー画面で「進捗中（ステップ〇）」が表示され、スムーズに再開できます。
- **全データリセットボタン**: 右上の「ゴミ箱」アイコン（HTMLダウンロードボタンの隣）から、ワンクリックで全データを安全に初期化可能。

### 3. 生活班編成ウィザード
- **班数・班名の自由設定**: 先生が事前設定した班名をワンクリックで呼び出し可能。
- **男女均等配分＆リーダー選出**: 各班の男女比率を均等に保ちつつ、班長（男子・女子）を指定可能。
- **自動シャッフル生成**: ペア制限を考慮して最適な班分けを自動算出。
- **生活班名簿の印刷＆Word保存**: A4用紙1枚にきれいに収まる印刷機能とWord（.doc）ダウンロードに対応。

### 4. 席替えジェネレーター
- **生活班情報のリアルタイム連動**: 編成済みの生活班をワンクリックで席替えに反映。
- **配置パターンの選択**: 「男女ランダム」または「市松模様（男女交互）」を選択可能。
- **空席・除外席のフリック/タップ指定**: 教室のレイアウト（空いている机や物置）に合わせて自由に空席を指定。
- **生活班ブロック配置**: 班ごとにまとまったブロック席を割り当て可能。
- **5秒カウントダウン演出**: クラス全員で盛り上がれるワクワクの自動生成カウントダウン。
- **クリックでの手動席入れ替え**: 生成後に微調整したい席を2つ選ぶだけで、生徒をその場で入れ替え。

### 5. 高品質A4印刷＆保存
- **A4用紙専用CSS対応**: はみ出しを防ぎ、生徒名が太字でくっきり印刷されます。
- **生徒用（教卓が上）／教師用（教卓が下）**: 視点切り替え＆両方まとめて印刷可能。
- **Word（.doc）およびHTML形式で保存可能**。

## 📂 GitHub用ファイル構成

GitHubにアップロードして利用する場合、以下のファイル構成になります：

```text
├── index.html            # メインアプリケーション（GitHub Pagesのトップページとして即座に動作）
├── sekigae_full_app.html # 配布・オフライン保存用（index.htmlと同内容の完全版スタンドアロンファイル）
├── README.md             # 本説明書
└── .gitignore            # Git除外設定
```

> **※ index.html は単一HTML（Single File）仕様**となっているため、JavaScript、CSS、アイコン（Lucide Icons）がすべて1つのファイル内に完全に内包されています。追加のアセットやサーバー設定は不要です。

## 🚀 利用方法

### 方法A: GitHub Pagesで公開・利用する場合（推奨）
1. GitHubで新規リポジトリ（例: `sekigae-app`）を作成します。
2. 本フォルダ内の `index.html`、`sekigae_full_app.html`、`README.md` をリポジトリにアップロード（またはプッシュ）します。
3. リポジトリの **Settings > Pages** を開きます。
4. **Build and deployment > Branch** で `main`（または `master`）の `/ (root)` を選択し、**Save** をクリックします。
5. 数十秒で発行される公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）にアクセスすれば、どの端末（PC、タブレット、スマホ）からでも利用できます。

### 方法B: パソコン上で直接利用する場合（オフライン・校務PC）
1. `index.html`（または `sekigae_full_app.html`）をダウンロードします。
2. ファイルをダブルクリックすると、Google Chrome、Microsoft Edge、Safari などのブラウザでそのまま起動します。
3. インターネット接続が一切ない環境でも快適に動作します。
4. 入力した名簿データや設定は、お使いのブラウザ内（LocalStorage）に安全に保持されます。
