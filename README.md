# 班編成＆席替えジェネレーター（スタンドアロン版）

先生専用のゼロ設定（生徒情報一括登録・ペア制限・位置希望）をもとに、班編成と席替え（市松模様・フリック空席調整・自動生成）を行う、**サーバー不要・API キー不要**の完全ブラウザ完結型アプリです。

- `index.html` … 本体アプリ（React 製フル機能版を1ファイルに単一化したもの。GitHub Pagesではこれがトップページとして表示されます）

ダブルクリックしてブラウザで開くだけで動作します。入力データはブラウザの `localStorage` に保存されます（サーバーには送信されません／端末・ブラウザごとに保存されるためデータは共有されません）。

### このバージョンでの変更点

- 班編成（生活班）の「役割分担票」ステップに、実際の係分担表を参考にした「松江二中プリセット」を追加しました。班を編成すると、保健・体育班／給食班／生活班／図書班／学習・文化班／整備・美化班の6班名と、班ごとの係名があらかじめ表示されます。ステップ1の「プリセットなしで実行」ボタンでオフにでき、班名・係名はいつでも自由に書き換えられます。
- アプリ内の「HTMLダウンロード」ボタン（アプリ自身を単一HTMLとして書き出す機能）は削除しました。GitHub Pagesで公開したページ自体がそのまま単一HTMLの配布物になるため不要と判断しました。
- 班編成ウィザードの「メンバーシャッフル」「役割分担（詳細設定）」「完成」画面で、班長2名（男子リーダー・女子リーダー）を常にメンバー一覧の先頭に表示するようにしました。
- 「メンバーシャッフル」画面で、入れ替えたい2人のメンバー（班長を除く）を順にタップするだけで、班をまたいで即座に入れ替えられるようになりました。
- 「班の人数設定」画面に「この人数配分を既定値として保存」ボタンを追加しました。押すと、現在の各班の男女人数配分がブラウザに保存され、次回このウィザードを開いたとき（クラス人数・班数が同じ場合）は均等配分の代わりにその配分が初期表示されます。
- 班編成の「班編成一覧表（決定した班の構成一覧・印刷/PDF用）」画面でも、班長2名を各班の先頭に表示するようにしました（メンバーシャッフル後・詳細設定・完成画面はすでに対応済みでしたが、こちらは対象外だったため追加しました）。
- 各画面に「保存する」ボタンを追加しました。ゼロ設定・生徒用メニュー・席替えの各ステップ画面では、右下に常時表示される「保存する」ボタンを押すといつでも明示的に保存でき、押した直後に保存完了メッセージが表示されます（これらの画面はボタンを押さなくても入力のたびに自動保存されており、ボタンは「今の内容が保存されている」ことを確認するためのものです）。班編成ウィザードは手順の途中経過が自動保存されない仕組みだったため、ウィザード画面上部に専用の「保存する」ボタンを新設し、押した時点の作業内容（班数・班名・人数配分・班長・シャッフル結果・係分担など）を保存できるようにしました。保存後にページを閉じたり再読み込みしても、同じ生徒名簿であれば保存した続きから再開できます。**保存されるデータはすべてこの端末のブラウザ内（localStorage）にのみ保存され、インターネットや外部サーバーには一切送信されません。**

## GitHub Pages で公開する手順

### 方法A：GitHub のWeb画面だけで完結（Gitコマンド不要）

1. GitHub にログインし、右上の「+」→「New repository」で新しいリポジトリを作成します（例: `sekigae-app`）。Public（公開）を選択してください。
2. 作成したリポジトリのページで「Add file」→「Upload files」をクリックし、このフォルダの中身（`index.html` など）をすべてドラッグ＆ドロップしてアップロード、「Commit changes」をクリックします。
3. リポジトリの「Settings」タブ →左メニューの「Pages」を開きます。
4. 「Build and deployment」の「Source」を **Deploy from a branch** に設定し、「Branch」を `main` ／ フォルダを `/ (root)` にして「Save」をクリックします。
5. 1分ほど待つと、ページ上部に公開URL（`https://<あなたのユーザー名>.github.io/<リポジトリ名>/`）が表示されるのでアクセスして動作を確認してください。

### 方法B：git コマンドを使う場合

```bash
cd publish   # このフォルダに移動
git init
git add .
git commit -m "Add standalone seating app"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git push -u origin main
```

その後、方法Aの手順3〜5と同様に GitHub の「Settings」→「Pages」で公開設定を行ってください。

## 補足

- フォントは Google Fonts（Inter / Noto Sans JP 等）をオンラインから読み込みます。GitHub Pages 上で開く場合はネットワークがあるため問題なく表示されますが、オフラインで `index.html` を直接開いた場合は代替フォントで表示されます（機能には影響ありません）。
- このファイルをコピーして配布・共有すれば、生徒用PCやタブレットでもそのまま動作します。
